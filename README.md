# Журнал пациентов — первый прототип

Локальное desktop-приложение на Python, Qt и SQLite. Визуальная часть повторяет согласованный светлый концепт: плоский sidebar, белые карточки, плотная таблица и постоянная форма быстрого ввода справа.

## Запуск

```powershell
cd C:\Project\jornal
python modern_app.py
```

Готовая Windows-сборка находится в `dist\JournalPatients\JournalPatients.exe`. Для запуска переносите всю папку `JournalPatients`, а не один `.exe`: в ней находятся библиотеки Qt.

Версионная сборка и ZIP-релиз создаются командой:

```powershell
python build_release.py
```

Для публикации собранной версии в сетевую папку обновлений:

```powershell
python build_release.py --publish-root "\\fs.acrb-amursk.ru\common\РАО\Пациенты\Jornal-oper"
```

## Что уже сделано

- журнал с SQL-пагинацией по 10 записей и фильтрами по ФИО и дате операции;
- быстрое добавление справа, редактирование выбранной записи;
- повторные операции одного пациента сохраняются как отдельные случаи с собственными внутренними `id`;
- обязательные поля: № истории, ФИО, дата операции, вид наркоза;
- автоматический расчёт длительности наркоза;
- справочники видов наркоза, врачей и медсестёр;
- выбор и смена пути к SQLite-базе;
- при недоступной базе показывается кастомное окно с повтором подключения и выбором другой базы;
- резервная копия при первом успешном запуске в каждой ISO-неделе: `backups/journal-ГГГГ-Wнн.db`.
- проверка более свежего релиза в `UPD` при закрытии и безопасное самообновление локальной сборки.

## Файлы данных

- `Jornal-oper\settings.json` — общие настройки, справочники и фактически используемый путь к базе.
- `%LOCALAPPDATA%\JornalPatients\connection.json` — только локальный указатель на выбранную общую папку, необходимый до подключения к сети.
- `Jornal-oper\data\journal.db` — общая база.
- `Jornal-oper\backups\` — недельные резервные копии базы.
- `Jornal-oper\UPD\` — опубликованные релизы и `latest.json`.

Фамилии в демонстрационном интерфейсе не создаются автоматически; база изначально пустая.
