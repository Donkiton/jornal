# Участие в проекте

## Изменения и pull request

- Работайте в отдельной ветке с понятным именем; не отправляйте изменения напрямую в `main`.
- Для каждого изменения создавайте pull request в `main` и описывайте, что изменилось и как это проверялось.
- Коммиты оформляйте на русском языке.

## Проверки и данные

- Перед pull request запускайте существующие тесты: `python -m unittest discover -s tests -v`.
- Не добавляйте в репозиторий реальные данные пациентов или медицинские сведения.
- Не добавляйте пароли, токены, ключи и другие секреты. Для примеров используйте вымышленные значения.

## Лицензия

В репозитории нет файла `LICENSE`. Публичная видимость репозитория сама по себе не является предоставлением лицензии на открытый исходный код или разрешения копировать, изменять и распространять проект.
